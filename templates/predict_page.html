What precisely is the price predictor?

The AutobAI price predictor is a way for our clients to evaluate and approximate the value of their automobiles


How does it function?

The AutobAI price preditor is essentialy a machine learning model trained on thousands of automobile listings and tuned to make predictions based on certain features of a machine that can indicate it's value


How to evaluate my automobile?

Input the required features of your machine into the corresponding fields and submit them, as effortlesly as that. The more fields completed and precise the input data is, the better the evaluation.

The AutobAI price predictor is a machine learning regression model and it's results should thus be treated purely as aproximations, not as professional evaluations of the value of automobiles.

Please note that the predictor does not take into account trims, the car's condition or additional modifications made to the machine that might influence it's value
